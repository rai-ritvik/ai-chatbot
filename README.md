# React AI Chatbot

A fast, responsive AI chatbot built with React and Redux Toolkit, powered by the Google Gemini 3.8 Flash model. 

## 🚀 Features
* **Real-Time AI Responses:** Integrated with Google's latest `gemini-3.8-flash` API.
* **Global State Management:** Chat history and loading states managed cleanly via Redux Toolkit.
* **Rich Text Formatting:** AI responses support full Markdown rendering (code blocks, lists, bold text) using `react-markdown` and Tailwind Typography.
* **Auto-Scrolling UI:** The chat window automatically snaps to the latest message.
* **Responsive Design:** Styled entirely with Tailwind CSS for a modern, clean interface.

## 🛠️ Tech Stack
* **Frontend:** React 18 (via Vite)
* **Styling:** Tailwind CSS
* **State Management:** Redux Toolkit
* **Network / API:** Axios
* **Formatting:** React Markdown
